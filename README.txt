PLAY STORE BICYCLE - LOCAL VS CODE VERSION
==============================================

Files:
- index.html
- style.css
- script.js
- images/showroom.jpg       <-- add your showroom photo here
- images/bike-collection.jpg <-- add your bicycle collection photo here

HOW TO RUN:
1. Extract/open this folder in VS Code.
2. Put your two photos inside the images folder:
   - showroom.jpg
   - bike-collection.jpg
3. Open index.html in VS Code.
4. Install the "Live Server" extension by Ritwick Dey if you do not already have it.
5. Right-click index.html -> Open with Live Server.
6. Your website will open in the browser.

IMPORTANT:
- This version is plain HTML + CSS + JavaScript.
- React, TypeScript, Tailwind, TanStack and Supabase were removed.
- The original enquiry form saved data to Supabase. This local version instead opens WhatsApp with the enquiry details.
- Google Maps and Google Fonts require an internet connection.
- The phone number, address, WhatsApp number, services, reviews and site wording were converted from the supplied Lovable project.
